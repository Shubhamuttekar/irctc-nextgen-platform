✨ Key Features in Redesigned Login Form:

  • Vande Bharat Header Banner: Authentic Indian Railways seal & IRCTC official circular logo.
  • Dual Persona Switcher: USER LOGIN vs AGENT LOGIN tabs with animated royal blue active underline.
  • Floating Pill Inputs: Soft rounded background, small top caption label, and right-aligned icons.
  • Password Visibility Eye Toggle: Instant one-click toggle between password masking and plain text.
  • Persistent Modal Shell: Full GPU entrance/exit animations without flashing or disappearing.

♿ Accessibility & Standards:

  • Full keyboard navigation: Tab cycle, Enter to submit, Escape to close.
  • WCAG AAA High Contrast mode compatibility with gold/obsidian inversion.
  • Multilingual support: compatible with English, Hindi, Bengali, Marathi, and Tamil.
