Accessibility Diagnosis & Architecture Review

A+ Font Scaling: Navigation Menu & Logo Overlap

Comprehensive root cause analysis and proposed dual-layer responsive strategy to eliminate collision between the capsule navigation menu and the official Government & IRCTC logos.

Current Scale:
Current Defect (As Shown In Screenshot)

Capsule Overflows Leftward onto IRCTC Logo

When data-font-size="lg" is active, the 7 navigation buttons expand to 880px+. Because the container uses justify-content: center without boundary protection, the excess width spills equally left and right, colliding with the branding cluster.

⚠️ OVERLAP BUG: HOME pill sits on IRCTC logo
🇮🇳
🚂
IRCTC INDIAN RAILWAYS
Helpline: 139
Underlying Root Causes:
1. html[data-font-size="lg"] scales 1rem to 18px (+12.5%), making the 7-tab pill wider than the available space.
2. .capsule-nav-bar has justify-content: center, which expands equally on both sides when overflowing.
3. .branding-cluster lacks flex-shrink: 0 and a rigid isolation boundary, allowing the pill to trespass over it.
Proposed Fix (Dual-Layer Responsive Architecture)

Adaptive Proportional Sizing & Rigid Logo Sanctuary

Under html[data-font-size="lg"], the capsule applies compact button padding (6px 11px) and micro-gap, shrinking the pill to fit with 100px+ margin. Logo cluster is shielded with flex-shrink: 0 and safe flex alignment.

IRCTC INDIAN RAILWAYS

Key Architectural Guarantees:
• ✅ Logo Sanctuary: .branding-cluster { flex-shrink: 0; } ensures the logos can never be compressed or overlapped.
• ✅ Adaptive Button Proportion: Under A+, buttons dynamically scale padding from 8px 16px to 6px 11px, preserving sleek single-row layout.
• ✅ Constrained Screen Safety: On smaller screens (<1280px) with A+, gracefully wraps capsule to a centered row 2, completely preventing collision.

Proposed Universal Implementation Plan

Precision CSS rules to be applied across the platform header to safeguard typography scaling across all screen resolutions:

Layer / Selector Proposed Rule Objective
Branding Sanctuary
.branding-cluster 		flex-shrink: 0 !important; z-index: 10; position: relative; Guarantees that the Lion Capital, Railways Seal, and IRCTC logo can never be encroached upon or squished by adjacent elements.
Capsule Bounds Protection
#capsule-nav-container 		min-width: 0; justify-content: safe center; Prevents flex items from overflowing to the left when container space is tight.
A+ Adaptive Capsule Scaling
html[data-font-size="lg"] .capsule-pill 		padding: 3px 6px !important; gap: 2px !important; Tightens outer capsule container padding when root font size is 18px.
A+ Adaptive Button Sizing
html[data-font-size="lg"] .capsule-btn 		padding: 6px 11px !important; font-size: 0.8rem !important; letter-spacing: 0.3px !important; Reduces button footprint by ~200px across the 7 tabs, allowing it to fit effortlessly on a single row alongside branding and actions.
Constrained Screen Wrap Fallback
@media (max-width: 1280px) 		html[data-font-size="lg"] .header-container { flex-wrap: wrap; }
html[data-font-size="lg"] #capsule-nav-container { order: 3; width: 100%; margin-top: 8px; } 		On smaller laptop screens running A+, allows the capsule menu to drop cleanly to a second centered row rather than causing layout distortion.
